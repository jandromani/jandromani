## Background

I started in **GIS and spatial systems**, then worked on enterprise Java applications, distributed architectures and technical leadership. Today I focus on **AI engineering and systems architecture**.

The thread running through that journey is systems thinking: understanding dependencies, clarifying responsibilities, making behavior observable and enabling other people to operate what has been built.

My core technical stack includes **Java, Python, TypeScript, Spring, Kubernetes, AWS and PostgreSQL**.

## Independent research

I also explore agentic systems, AI governance, computer vision, spatial computing, simulation, generative media and human–AI interfaces. Some experiments become open-source tools, documented prototypes or interactive exhibits; others remain research.
